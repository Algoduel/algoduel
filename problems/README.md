# Задачи

Каждая задача — отдельная папка:

```
<id>/
  statement.md        условие
  problem.yaml        параметры: чекер, лестница для каждого языка, режимы тестов
  solutions/ref.cpp   эталон на C++
  solutions/ref.py    эталон на Python (тот же класс сложности!)
  gen/main.go         генератор: -n, -seed, -mode
```

Пример — `sort-numbers`. Задачи с LeetCode и других сайтов брать нельзя, пишем свои.

Чек-лист новой задачи:

- [ ] Генератор умеет случайные данные и худшие случаи
- [ ] Эталоны на C++ и Python дают одинаковые ответы
- [ ] Рост затрат эталонов между ступенями совпадает (одинаковая асимптотика)
- [ ] Верхняя ступень: эталон укладывается в бюджет с запасом ×2
